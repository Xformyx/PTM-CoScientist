# PTM-CoScientist

**PTM-CoScientist** is an autonomous AI agent system designed to accelerate scientific discovery in Post-Translational Modification (PTM) research. It acts as a "Research Collaboration Agent" (Scientist-in-the-loop) that generates, debates, and evolves biological hypotheses based on raw PTM data, and proposes concrete experimental designs to validate them.

This project is built as a **standalone, read-only consumer** of the existing [PTM-platform](https://github.com/Xformyx/PTM-platform). It safely reads intermediate artifacts (JSON files, ChromaDB literature collections) generated by PTM-platform without modifying its core pipeline.

## 🧬 Architecture

Inspired by Google DeepMind's "Co-Scientist" (Nature, 2026), this system implements a multi-agent **Generate → Debate → Evolve** pipeline.

### Agent Pipeline
1. **Generator Agent (`src/agents/generator.py`)**
   - Consumes PTM-platform artifacts (Enriched PTMs, Kinase Modules, Signal Flow, Co-movement clusters).
   - Generates structured `IF → THEN → BECAUSE` hypotheses.
2. **Debater Agent (`src/agents/debater.py`)**
   - Validates hypotheses against existing literature in PTM-platform's ChromaDB.
   - Runs a pairwise debate tournament to critically evaluate biological plausibility, novelty, and testability.
   - Ranks hypotheses using an Elo rating system.
3. **Evolver Agent (`src/agents/evolver.py`)**
   - Takes top-ranked hypotheses and their debate critiques.
   - Strengthens, combines, or diverges them into more robust and novel hypotheses.
4. **Experiment Designer (`src/agents/experiment_designer.py`)**
   - Translates the final top hypotheses into actionable laboratory protocols (e.g., Western Blot, LC-MS/MS, Kinase assays).
   - Suggests specific reagents, controls, and expected outcomes.

### Integration with PTM-platform (Method B)
PTM-CoScientist is completely decoupled from PTM-platform's core processing:
- **`PTMPlatformConnector`**: Reads `enriched_ptm_data.json`, `kinase_modules.json`, etc., from a read-only mounted volume.
- **`ChromaDBConnector`**: Queries PTM-platform's existing RAG collections via HTTP API for evidence validation.

## 🚀 Getting Started

### Prerequisites
- Python 3.11+
- Access to a running instance of PTM-platform (for ChromaDB and output files)
- LLM Provider (Ollama, OpenAI, or Gemini)

### Installation

```bash
# Clone the repository
git clone https://github.com/Xformyx/PTM-CoScientist.git
cd PTM-CoScientist

# Install dependencies
pip install -e .
```

### Configuration
Set the following environment variables (or configure via `.env`):
```bash
export LLM_PROVIDER=auto  # auto | ollama | openai | gemini
export OLLAMA_URL=http://localhost:11434
export LLM_MODEL=gemma3:27b
export CHROMADB_URL=http://localhost:8000  # Point to PTM-platform's ChromaDB
export PTM_ARTIFACTS_DIR=/path/to/PTM-platform/data/outputs
```

### Usage (CLI)

Run the Co-Scientist pipeline for a specific PTM-platform order:
```bash
coscientist run ORDER_12345 --goal "Find novel therapeutic targets for liver fibrosis" --iterations 3
```

View the generated results:
```bash
coscientist show /data/coscientist/outputs/ORDER_12345/results.json
```

### Usage (API Server)

Start the REST API server for Scientist-in-the-loop interactions:
```bash
coscientist serve
```
The API provides endpoints to start sessions, retrieve current state, and submit human feedback to guide the evolution of hypotheses.

## 🐳 Docker Deployment

```bash
# Set the path to your PTM-platform data directory
export PTM_PLATFORM_DATA_DIR=/path/to/PTM-platform/data/outputs

docker-compose up -d
```
